# Тихий контракт

Браузерная 3D стелс-песочница с видом от третьего лица, вдохновлённая жанром «убийцы в маскировке». Одна большая локация, свои персонажи и сюжет.

**Вилла «Серено», озеро Ардо.** Закатный вечер, закрытый винный аукцион. Агент под позывным «Ворон» должен устранить торговца оружием Виктора Кесслера и его финансиста Марту Вейл, не поднимая шума, и уйти.

## Запуск

Нужен Node.js 20.19+ (или 22.12+).

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно http://localhost:5173).

Сборка статической версии (папка `dist/`, можно открыть через любой статический сервер):

```bash
npm run build
npm run preview
```

## Управление

| Клавиша | Действие |
| --- | --- |
| W A S D, мышь | Движение и камера |
| Shift | Бег |
| C / Ctrl | Присесть / красться |
| E | Основное действие: двери, предметы, тела, укрытия, выходы |
| R | Дополнительное действие: переодеться, рвотное средство |
| F | Обезвредить / устранить / столкнуть |
| ПКМ / ЛКМ | Прицелиться / выстрел или бросок |
| 1–9, колесо мыши | Выбор предмета, 0 или H — убрать |
| G | Выбросить предмет |
| Q (удерживать) | «Чутьё»: видеть людей сквозь стены |
| J | Переключить отслеживаемую возможность |
| Tab / M | Карта и задания |
| Esc | Пауза |

## Что есть в игре

- **Локация** с зонами доступа: главный зал с баром и пианистом, галерея с аукционом, хранилище, кабинет, кухня, служебные помещения, терраса, сад, пирс, эллинг, винный погреб, пост охраны, служебный двор, оранжерея и сарай садовника.
- **Около 50 NPC** со своими распорядками дня: гости, официанты, повара, бармен, сомелье, садовник, техник, охрана, телохранитель и две цели.
- **Маскировки.** Одежду можно снять с обезвреженного человека. Каждая маскировка открывает свои зоны. Отдельные люди («тот, кто может узнать») способны раскусить маскировку своих коллег.
- **Восприятие.** Конусы зрения с учётом препятствий и высоты укрытий, шкала подозрения, предупреждения, выдворение нарушителя охраной, доклады охране, поиски, бой.
- **Социальный стелс.** Монеты для отвлечения, укрытия в шкафах, тела можно прятать в контейнеры. Найденные тела поднимают тревогу.
- **Пять «возможностей»**, то есть сюжетных способов устранения. Их можно подслушать в разговорах NPC. Отравить графин, столкнуть с пирса, подсыпать яд в мартини, выдать себя за оценщика, застать цель наедине в кабинете.
- **Итоги миссии:** рейтинг, «Бесшумный убийца», 10 испытаний. Прогресс сохраняется в браузере.
- **Графика:** процедурные текстуры и модели (без внешних ассетов), PBR-материалы, закатное небо, озеро с отражениями, тени, GTAO, bloom, цветокоррекция.
- **Звук:** всё синтезируется на лету через WebAudio: выстрелы, двери, гул вечеринки, пианист, музыка тревоги.

## Структура

```
src/
  core/      ввод, утилиты
  render/    рендер, постобработка, процедурные текстуры и материалы
  world/     коллизии, навигационная сетка (A*), сборщик уровня, реквизит, двери
  entities/  процедурная модель человека, игрок, ИИ персонажей, одежда
  game/      игровой цикл, камера, системы (тревога, бой, предметы), миссия, звук, реплики
  levels/    вилла «Серено»: геометрия, зоны, точки маршрутов, NPC и их диалоги
  ui/        HUD с миникартой, меню, карта, экран итогов
```

## Отладка

- `?debug`: не ставить игру на паузу при потере захвата мыши.
- `?quality=low|medium|high`: принудительное качество графики.
- В консоли доступен `__game`, например `__game.simulate(30)` прокручивает 30 секунд симуляции без отрисовки.

Персонажи, места и события вымышлены.
